# Aplikasi Katalog Produk (JavaFX) pengimplementasian mata kuliah Pemrograman Lanjut

Nama  : Nadisya Azkia Syifana

NIM   : 2501186

Kelas : 3B

Saat ini saya telah membuat aplikasi desktop berbasis JavaFX dan database SQLite untuk mengelola data katalog produk dengan operasi CRUD (Create, Read, Update, Delete) secara lengkap.

# Fitur Utama
- Menambahkan data produk baru (nama, harga, dan foto produk) lengkap dengan validasi input.
- Menampilkan daftar produk dalam bentuk kartu katalog interaktif beserta penghitung jumlah produk.
- Fitur Edit untuk memperbarui data produk yang sudah tersimpan di database.
- Fitur Hapus untuk menghapus produk dengan dialog konfirmasi keamanan.
- Penyimpanan data lokal secara persisten menggunakan database SQLite (`data/katalog.db`).
- Tampilan antarmuka yang menarik dan dikustomisasi menggunakan stylesheet CSS.

# Persyaratan Sistem
- Java Development Kit (JDK) 11 atau lebih baru.
- Apache NetBeans IDE (dengan dukungan Apache Maven).
- SQLite JDBC & JavaFX.

# Cara Menjalankan Proyek
1. Clone atau unduh repositori ini.
2. Buka proyek `KatalogProduk` menggunakan **Apache NetBeans**.
3. Buka package `main` dan cari file `MainApp.java`.
4. Klik kanan pada file `MainApp.java` -> pilih **Run File** (atau tekan `Shift + F6`), atau jalankan proyek melalui **Run Project** (`F6`).
